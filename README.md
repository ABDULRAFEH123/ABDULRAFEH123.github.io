# Abdul Rafeh · Frontend Developer

Personal portfolio: **https://abdulrafeh123.github.io/**

A one-page, scroll-driven portfolio built with plain HTML, CSS and JavaScript, animated with GSAP ScrollTrigger and Lenis smooth scrolling.

- Animated loader and hero that folds into a floating glass sidebar on scroll
- About section with a self-drawing scroll path and tilt cards
- Pinned horizontal project rail: DojoWhiz, TrackHero, MotorCut
- Responsive down to phones, respects `prefers-reduced-motion`

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
